# Chores List App Plan

## Scope

The app will allow family members to manage shared household chores by tracking chores, assigning them to specific individuals, and monitoring progress.

## User Interface and Design

### Home Screen
- **Top Section**:
  - Today's chores displayed in a table format.
  - Each chore assigned against a person.
- **Bottom Section**:
  - Weekly progress bar showing chore completion.
- **Navigation Buttons**:
  - Home, Chores, Calendar, Settings.

### Chores List Screen
- **Top Section**:
  - Back to Home button.
- **Chore Sections**:
  - General chores and room-specific chores.
- **Chore List**:
  - List of chores with options to add, edit, or delete.
- **Completion Indicator**:
  - Checkbox or button to mark chores as completed.

### Calendar Screen
- **Top Section**:
  - Back to Home button.
- **View Selector**:
  - Options to switch between monthly and weekly views.
- **Chore Details**:
  - Detailed chores for the selected day.
- **Navigation**:
  - Back to Home button.

### Settings Screen
- **Top Section**:
  - Back to Home button.
- **Reminders Configuration**:
  - Options to enable/disable reminders and set times.
- **Family Members Configuration**:
  - List of family members with options to edit their chores and points.
- **Navigation**:
  - Back to Home button.

### Leaderboard Screen
- **Top Section**:
  - Back to Home button.
- **Leaderboard Display**:
  - Chore points and completion rates.
- **Navigation**:
  - Back to Home button.

## User Flow and Navigation

1. **Login/Registration**:
   - Users can create an account or log in if they already have one.

2. **Home Screen**:
   - Users see today's chores, weekly progress, and navigation buttons.
   - Navigation to Chores List, Calendar, and Settings.

3. **Chores List Screen**:
   - Users can view chores by section, add, edit, or delete chores.
   - Navigation back to Home Screen.

4. **Calendar Screen**:
   - Users can switch between monthly and weekly views.
   - Clicking on a specific day shows detailed chores.
   - Navigation back to Home Screen.

5. **Settings Screen**:
   - Users can configure reminders and family members.
   - Navigation back to Home Screen.

6. **Leaderboard Screen**:
   - Users see chore points and completion rates.
   - Navigation back to Home Screen.
